# Barbados News: GitHub Pages portal

## Two publication sources

1. **Telegraph:** existing `data/articles.json` (generated by MultiAccount). The updater does not touch this file.
2. **BarbadosNews.com:** `https://barbados-news.com/feed/` (RSS), supplemented by WordPress public REST API for featured images when available. Cached in `data/barbados_feed.json`.

## Installation into the existing repository

Repository: https://github.com/djcongr-byte/barbados-news

1. Extract the ZIP file.
2. Open **Add file → Upload files** in the existing GitHub repo.
3. Drag the **contents of the extracted directory** into GitHub. Include `.github`, `scripts`, `site_assets`, `data/barbados_feed.json`, `site.json`, and `README.md`.
4. Commit changes to `main`.
5. Open **Actions → Build Barbados News portal** to view deployment. To refresh immediately use **Run workflow**.

**NEVER delete or replace `data/articles.json`: it is intentionally not included in this ZIP.**
**Do not upload the ZIP itself as a file into the repository; GitHub Pages does not extract ZIP files.**

GitHub Actions rebuilds on every MultiAccount commit, every hourly RSS refresh (around :17 UTC), changes to design files, and manual dispatch. The schedule is best-effort and can be delayed. The WordPress snapshot is kept on API failures.

## Page structure

- `/` — news and Telegraph article cards (without fabricated images)
- `/news/` — original BarbadosNews announcements with images and excerpts
- `/archive/` — **all** Telegraph links, existing path preserved
- `/topics/<slug>/` — the original Telegraph topic paths
- `/topics/` — topic directory
- `/search/` — browser-side search across both sources
- `/tools/` — working tools on barbados-news.com
- `/feed.xml`, `/sitemap.xml`, `/robots.txt`

## Local build

Requires Python 3.10+ (no extra packages):

```bash
python3 scripts/fetch_wordpress.py
python3 scripts/build_site.py
```

For a local preview set `SITE_URL=http://localhost:8000`, run `python3 scripts/build_site.py`, then start `python3 -m http.server 8000 -d _site`. The deployed site uses the correct HTTPS URL automatically.

## Security and publishing

- No credentials or WordPress plugin required.
- RSS is fetched in GitHub Actions, avoiding WordPress CORS restrictions in the browser.
- URL hosts are validated and HTML output is escaped.
- Existing Telegraph links are external and not overwritten.
- Live cryptocurrency prices are intentionally **not** fabricated.
- WordPress updates are displayed as **summaries linking to the original post**.
- If RSS and REST APIs are unavailable, previously cached news stays available. A first-run failure displays a placeholder until a successful run.
